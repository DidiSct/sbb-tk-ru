Cadangkan & Pulihkan Data

Unduh seluruh data sekolah (siswa, guru, absensi, pembayaran, perkembangan, kegiatan, pengumuman, pengguna) beserta foto galeri sebagai satu berkas cadangan lengkap, atau pulihkan dari berkas cadangan sebelumnya.
Aplikasi ini menyimpan data dalam database SQLite di perangkat ini. Unduh berkas .db mentahnya untuk cadangan data terstruktur (bisa dibuka & di-query dengan aplikasi seperti DB Browser for SQLite). Berkas akan tersimpan di dalam folder data/ pada folder Downloads perangkat Anda (berlaku di Chrome/Edge/Firefox di laptop & Android; di Safari/iPhone berkas tetap tersimpan langsung di Downloads tanpa sub-folder, karena keterbatasan Safari). Catatan: foto galeri disimpan terpisah agar aplikasi tetap ringan & cepat, sehingga tidak ikut termuat dalam berkas .db — gunakan cadangan .json di atas jika ingin foto ikut tercadangkan.
